# IPL Teams & Venues Dashboard

1. Put `teams.csv` and `venues.csv` next to `app.py` (or in a nearby `data` folder).
2. Open this folder in VS Code.
3. Run in the terminal:
   `C:\\Users\\asfan\\miniconda\\envs\\project_4_streamlit_venv\\python.exe -m pip install -r requirements.txt`
4. Then run:
   `C:\\Users\\asfan\\miniconda\\envs\\project_4_streamlit_venv\\python.exe -m streamlit run app.py`

The dashboard contains overview cards, a city chart, team and venue tables, filters, downloads, and data-quality checks.
It uses only teams and venues data; it does not invent match/player statistics.
